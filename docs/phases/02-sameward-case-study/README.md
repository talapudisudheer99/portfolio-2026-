# Phase 02 — Homepage + Sameward narrative

**Goal:** Build an engaging homepage where Sameward is the visual and narrative
center, without turning the entire page into a long technical document.  
**Status:** ⬜ Blocked on Phase 01

## Homepage composition

- [ ] Hero: oversized two- or three-line statement; concise proof line; one
  primary CTA and one text action
- [ ] Place Sameward immediately after the hero
- [ ] Capabilities: editorial columns or sentence-led proof, no cards/pill cloud
- [ ] Experience: selective ruled rows, not repeated containers
- [ ] Profile/About: condensed story with factual signals integrated into the
  composition, not a paragraph beside a stats box
- [ ] Contact: large closing statement, visible email, resume and social links
- [ ] Update nav labels/order to match the final IA

## Sameward feature

- [ ] Present preview/architecture as full-bleed or breakout media bands, not
  inset `rounded-xl` widgets inside `max-w-3xl`
- [ ] Use one strong, large product visual as the entry point; remove the fake
  browser frame if it makes the screenshot feel smaller
- [ ] Replace placeholder SVG with real product screenshots when supplied
- [ ] Use a sticky visual / scrolling narrative on desktop, normal flow on mobile
- [ ] Keep the scan path: problem → product → architecture → decisions → built →
  proof
- [ ] Convert architecture to a clear 2D DOM/SVG editorial graphic
- [ ] Show only the most persuasive 3–5 technical decisions on the homepage
- [ ] Keep live CTA to https://sameward.com/
- [ ] Decide whether deeper details belong on `/work/sameward`; create it only
  if homepage scanning becomes too long

## Content hierarchy

- Outcome and product value before stack.
- Decisions and trade-offs before badge lists.
- One visual idea per viewport; avoid multiple bordered diagrams stacked
  vertically.
- Sameward’s Ocean Blue may dominate its media region while the portfolio canvas
  stays warm-neutral.

## Out of scope

- WebGL / Three.js
- Decorative “tech” backgrounds

## Done when

Within 30 seconds, a recruiter can identify Sudheer’s role, open Sameward,
understand what was built end-to-end, and find experience/contact without
scrolling through repeated boxes.
